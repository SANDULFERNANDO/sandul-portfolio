# Sandul Fernando | Portfolio

A modern, responsive personal portfolio website built with Next.js.

**Live Website:** [https://sandulfernando.me](https://sandulfernando.me)

---

## About

I’m an IT undergraduate at Rajarata University of Sri Lanka, building my path toward technical project management. This portfolio reflects my approach to work:

**Think. Plan. Execute.**

It showcases selected projects and highlights my interest in the intersection of technology, people, and structured execution.

---

## Features

- Fully responsive design (Desktop & Mobile)
- Dark / Light mode toggle
- Smooth animations with Framer Motion
- Clean and modern UI
- Project showcase section
- Skills marquee
- Contact section
- Fast performance with Next.js App Router

---

## Tech Stack

| Category       | Technology              |
